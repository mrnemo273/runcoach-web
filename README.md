# RunCoach Web

A web app to track your running progress with AI-powered screenshot extraction.

## Features

- 📸 Upload Apple Watch/Fitness app screenshots
- 🤖 AI extracts run data automatically (distance, time, pace, heart rate, etc.)
- 💪 Track how you feel after each run
- 📝 Add notes about your runs

## Setup

1. Clone this repository
2. Deploy to Vercel
3. Add your `ANTHROPIC_API_KEY` in Vercel environment variables

## Tech Stack

- Next.js 14
- React 18
- Anthropic Claude API (for image extraction)
